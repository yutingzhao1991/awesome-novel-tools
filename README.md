## 简介

本列表收录与小说创作相关的各类工具，涵盖：

- **AI 写作**：AI 续写、生成、润色、大纲，以及可免费用于写小说的通用大模型应用
- **传统写作软件**：Scrivener、yWriter 等专为作家设计的写作工具
- **创作配套**：大纲规划、世界构建、校对编辑、排版出版
- **开源生态**：可自托管的 AI 写作前端、本地推理引擎、开源写作软件与写作模型
- **社区资源**：写作社区、awesome 列表、提示词库与教程

> ⚠️ 说明：工具信息（价格、运营状态）更新频繁，请以官网为准。标注「已停运」的工具请勿再推荐。

## AI 小说写作工具（中文）

### AI 续写 / 生成

- [FeelFish](https://www.feelfish.com) - 为小说创作者设计的 AI 写作 Agent（桌面端）：多智能体协作、智能上下文续写、一键人物与世界观构建，支持 DeepSeek、ChatGPT、Kimi 等主流大模型。（AI 生成 / Win·macOS·鸿蒙 PC / 积分制）
- [彩云小梦](https://caiyunai.com) - 老牌中文 AI 续写工具，输入上文续写下文，2019 年上线，是中文 AI 续写赛道的开创者之一。（AI 续写 / Web+App / 免费额度+会员）
- [笔灵AI写作](https://ibiling.cn) - 综合性中文 AI 写作平台，小说垂直功能较全：大纲、人设、章节续写、文风改写。（AI 生成 / Web / 订阅制）
- [马良写作（MaliangWriter）](https://maliangwriter.com) - 面向中文网文的多智能体 AI 小说创作平台：三级大纲、知识图谱一致性、长篇连载；提供免费的大纲/人设生成器。（AI 生成 / Web / 免费+付费）
- [星火网文助手](https://www.sparkx.zone/tools/writerdesk.html) - 科大讯飞 2024 年推出的网文垂直写作助手，专为网文作者设计，支持大纲、人设、章节续写、取名、润色。（AI 生成 / Web / 免费额度为主）

### AI 写作助手 / 润色

- [秘塔写作猫](https://xiezuocat.com) - 秘塔科技的中文 AI 写作助手，校对、纠错、润色能力强，适用多种文体（含小说）。（AI 润色 / Web+App / 免费+会员）
- [讯飞智文](https://zhiwen.xfyun.cn) - 科大讯飞旗下写作工具，可免费生成故事与文案，评测反馈故事创作能力出色。（AI 生成 / Web / 免费为主）
- [文涌 Effidit（腾讯）](https://effidit.qq.com) - 腾讯 AI Lab 的智能创作助手，支持智能纠错、润色、补全与灵感生成，2.0 发布后更新放缓（半沉寂状态）。（AI 润色 / Web+插件 / 曾免费开放）

- [通义千问（阿里）](https://tongyi.aliyun.com) - 阿里大模型 C 端应用，可写故事与小说，2025 年月活快速增长。（通用 AI / Web+App / 免费+会员）
- [DeepSeek（深度求索）](https://www.deepseek.com) - 2025 年初爆火的国产开源大模型，免费、强推理、长文本，被大量用户用于找灵感、续写、润色；阅文等行业方已部署接入。（通用 AI / Web+App / 免费为主）

- [DeepStory](https://www.deepstory.ai) - AI 辅助虚构写作工具，主打「故事圣经」（Story Bible）维护角色与世界观一致性。（AI 辅助 / Web / 免费试用+订阅）
- [NovelistAI](https://novelistai.com) - AI 小说写作服务，强调跨章节保持角色一致性。（AI 生成 / Web / 免费层+订阅）

- [yWriter](https://www.spacejock.com/yWriter.html) - 免费的 Windows 小说写作软件，按章节/场景组织，自动统计字数。（写作软件 / Windows / 免费）
- [Dabble](https://www.dabblewriter.com) - 跨平台云端小说写作软件，界面简洁，支持大纲、角色与世界观管理。（写作软件 / Web+App / 订阅约 $10–20/月）
- [Wavemaker](https://wavemaker.cards) - 免费开源的网页版小说规划与写作软件（PWA），全平台可用。（写作软件 / Web / 免费开源）
- [Squibler](https://www.squibler.io) - 网页版小说写作软件，含 AI 辅助与协作功能。（写作软件 / Web / 订阅）
- [Novlr](https://www.novlr.org) - 专为小说家设计的网页写作平台，界面专注，含免费层。（写作软件 / Web / 免费层+订阅）
- [Ulysses](https://ulysses.app) - 优雅的 Apple 生态写作应用，支持长文档组织与导出。（写作软件 / Mac·iOS / 订阅约 $40–50/年）
- [iA Writer](https://ia.net/writer) - 极简专注的写作应用，Markdown 友好，支持语法高亮。（写作软件 / 多平台 / 低价订阅）
- [Effie](https://www.effie.co) - 中文团队出品的「写作+思维导图」软件，界面清爽，支持中文友好。（写作软件 / 多平台 / 免费+Pro）
- [novelWriter](https://github.com/vkbo/novelWriter) - 开源专为写小说设计的纯文本编辑器（Markdown 风格），含大纲、章节、角色管理。（写作软件 / Win·Mac·Linux / 免费开源 GPL-3.0）
- [Manuskript](https://github.com/olivierkes/manuskript) - 面向作家的开源写作工具：大纲、角色卡、思维导图式结构。（写作软件 / 多平台 / 免费开源 GPL-3.0）
- [bibisco](https://github.com/andreafeccomandi/bibisco) - 开源小说写作软件，侧重角色、情节、世界观分析与叙事结构。（写作软件 / 多平台 / 免费开源 GPL-3.0）
- [纯纯写作](https://writer.drakeet.com) - 安卓端口碑极佳的中文写作应用，专注、防丢失、支持长文。（写作软件 / Android / 免费+Pro）
- [Typora](https://typora.io) - 简洁的 Markdown 编辑器，适合写作与整理稿子。（写作软件 / 多平台 / 买断制 $14.99）

## 本地推理与写作模型

> 可用于写作的开源模型；许可证以各仓库 / 模型卡为准。

- [RWKV-LM](https://github.com/BlinkDL/RWKV-LM) - RNN 架构大模型，长上下文、低显存，社区广泛用于小说续写/生成。（Apache-2.0 / ≈1.5 万★）
- [Qwen3（通义千问 3）](https://github.com/QwenLM/Qwen3) - 阿里通义千问系列，中文写作能力强。（权重 Apache-2.0 / ≈2.8 万★）
