# Contributing Guide

Thanks for your interest in **Awesome Novel Tools**! Pull requests are welcome.

> 中文版：[贡献指南](CONTRIBUTING.md)

## Checklist

Before submitting a new tool, please make sure:

- [ ] The tool **actually exists and is accessible** (provide an official site / GitHub repo link)
- [ ] It is related to **novel / fiction writing** (writing, outlining, worldbuilding, polishing, editing, formatting & publishing, etc.)
- [ ] It is not on the "discontinued / no longer maintained" list (or you can prove it is still active)
- [ ] Provide an **objective** one-line description (no marketing hype)
- [ ] Include as much as possible: category, platform, free/paid, best fit for which kind of fiction

## Entry Format

Add one line to the matching category in `README.en.md`:

```markdown
- [Tool Name](official site or repo URL) - A one-line objective description. (Category / Platform / Free or Paid)
```

### Example

```markdown
- [Scrivener](https://www.literatureandlatte.com/scrivener/overview) - A powerful long-form novel writing app with outlining, chapter management and research features. (Writing software / Win·Mac·iOS / One-time purchase)
```

## Notes

- Keep entries sorted consistently with neighboring lines (alphabetical or by quality).
- If the tool is an **official platform tool** (e.g. a publisher's own app), note "platform tool".
- If the tool has been **discontinued**, move it to the "Discontinued / Inactive" section instead of deleting it.
- After editing `README.en.md`, please **also update `README.md`** (the Chinese version).

## Workflow

1. Fork this repo
2. Create a branch: `git checkout -b add-tool-xxx`
3. Edit `README.en.md` (and `README.md` if needed)
4. Commit, push, and open a Pull Request titled like: `Add: Tool Name`
